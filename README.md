🗺️ Medidor de Distancias y Tiempos en Mapa Real

Aplicación que permite medir distancias reales sobre un mapa, calcular tiempos estimados de recorrido y considerar factores como semáforos, paradas y tiempo total de viaje.

Pensado para análisis urbano, movilidad, simulaciones de tráfico y planificación de rutas.


✨ Features

📍 Medición de distancias reales en mapa

🧭 Selección de puntos origen/destino

⏱️ Cálculo de tiempo total de recorrido

🚦 Consideración de tiempos en semáforos

🛑 Soporte para paradas intermedias

🗺️ Mapa interactivo en tiempo real

📱 Responsive (desktop / mobile)
